Malware is software that works against you — stealers, ransomware, unwanted browser helpers. At home and in a small shop it usually arrives through a rushed download, a fake update, or an email attachment that looked ordinary.

You do not need five “optimiser” tools. You need boring defaults that stay on — because most trouble I see is self-invited, not a Hollywood hack.

Protected enough

  • Windows Security / Defender (or Mac equivalents) left on
  • Auto-updates for the operating system and browsers
  • Apps from official stores when you can
  • One reputable extra tool only if you have a clear reason

A living-room vignette

A free editor from a search ad brings a browser helper. Ads multiply. Bookmarks misbehave. Nobody “got hacked” in a film sense — the household installed something it did not mean to.

Phones count

Phones hold mfa and banking. Do not ignore operating system updates for months. Avoid mystery profiles. If pop-ups take over, stop entering passwords and get a clean look.

If a device already feels wrong

Stop entering banking passwords on it. From a different known-good phone or computer, change email and banking passwords and review sessions. Uninstall recent mystery apps. Run the built-in security scan. If ransomware messages appear, disconnect from Wi‑Fi and contact your bank and Action Fraud if money or crime is involved.

A self-check

When did you last install something you were not actively searching for? If an install was not something you went looking for on purpose, that is the habit to catch — decline it, close the tab, and open Settings yourself if an update is genuinely needed.
