Malware is software that works against you — stealers, ransomware, unwanted browser helpers. At home and in a small shop it usually arrives through a rushed download, a fake update, or an email attachment that looked ordinary.

You do not need five “optimiser” tools. You need boring defaults that stay on.

Use built-in protection, keep it updated, and treat unexpected install prompts as uninvited guests.

1. Protected enough

  • Windows Security / Defender (or Mac equivalents) left on
  • Auto-updates for OS and browsers
  • Apps from official stores when you can
  • One reputable extra tool only if you have a clear reason

2. A living-room vignette

A free editor from a search ad brings a browser helper. Ads multiply. Bookmarks misbehave. Nobody “got hacked” in a film sense — the household installed something it didn’t mean to.

3. Phones count

Phones hold MFA and banking. Don’t ignore OS updates for months. Avoid mystery profiles. If pop-ups take over, stop entering passwords and get a clean look.

Official reporting for cybercrime in the UK starts at Action Fraud when something has gone wrong.

4. What to do if a device already feels wrong

Stop entering banking passwords on it. From a different known-good phone or computer, change email and banking passwords and review sessions. Uninstall recent mystery apps. Run the built-in malware / security scan. If ransomware messages appear, disconnect from Wi‑Fi, keep the machine powered for advice if needed, and contact your bank and Action Fraud if money or crime is involved.

Backups matter here. A clean reinstall is survivable if yesterday’s files still exist somewhere the malware did not reach. That is why “protected enough” includes both prevention and a restore you have actually tried once.

For kids’ tablets and shared lounge laptops, keep admin rights with an adult account. Curiosity plus a free game installer is still one of the most reliable malware delivery routes in family homes — no targeted attacker required.

If an install wasn’t something you searched for on purpose, decline it.
